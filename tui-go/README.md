# Max+ TUI

Полноэкранный терминальный мессенджер на Go для [Max Messenger](https://max.ru), работающий через D-Bus демон `maxplus-daemon`.

## Возможности

- Split-pane интерфейс: список чатов слева, диалог справа.
- Статусы сообщений: отправлено / доставлено / прочитано.
- Индикатор `печатает...` (получение и отправка typing).
- Автообновление чатов, сообщений и статуса.
- Отметка чата прочитанным при открытии.

## Требования

- Запущенный `maxplus-daemon serve` с авторизованной сессией.
- Go 1.21+ (для сборки).

## Сборка и запуск

```bash
cd tui-go
go build -o maxplus-tui .
./maxplus-tui
```

## Клавиши

| Клавиша | Действие |
|---|---|
| `↑/↓`, `j/k` | Навигация по чатам |
| `Enter` | Открыть чат / отправить сообщение |
| `Tab` | Переключить фокус чаты/ввод |
| `Esc` | Вернуться к списку чатов |
| `PgUp/PgDn`, `↑/↓` в вводе | Скролл сообщений |
| `Ctrl+U` | Очистить ввод |
| `Ctrl+R` | Обновить |
| `q` | Выход из списка чатов |
| `Ctrl+C` | Выход |
